If I do slip into tech-speak at any point, please stop me and ask. There are no silly questions here. I want to explain a technical problem that affects your work too: what it is, what it means for you, and what we're doing about it.

Let me start with the short version, in one sentence: {{ argument_problem_one_sentence_summary }}

For the longer version, a picture helps more than technical detail.

The best way I can describe it is with an everyday comparison. {{ argument_everyday_analogy }} That's essentially what's happening in our system right now.

So why did this happen? In simple terms, {{ argument_plain_language_cause }}. I want to be clear that this isn't about one person making a mistake.

Now, the most important part for you: how does this affect your work?

What you might notice: {{ argument_visible_impact_for_colleagues }}

And what is not affected, so you don't need to worry about it: {{ argument_what_is_not_affected }}

I know this is frustrating, especially for those of you who deal directly with customers. So if customers ask you about it, here's a simple message you can use: {{ argument_customer_facing_message }} Please don't promise a specific fix date to customers for now. I'll explain why in a moment.

What are we doing about it?

We're working on it in two steps. The first step is a quick, temporary fix: {{ argument_short_term_fix }}. This won't solve the root problem, but it should reduce the impact while we work on the real solution. We expect this to be in place by {{ argument_short_term_fix_eta }}.

The second step is the permanent fix: {{ argument_long_term_fix }}. This takes longer, because we need to make the change carefully and test it properly. If we rush it, we risk causing new problems, which is the last thing anyone wants. Our current estimate is {{ argument_long_term_fix_eta }}. But this is an estimate, not a promise. Sometimes, once we start working on a fix, we discover something we didn't expect. That's why I'd rather not give customers a firm date yet. As soon as we're more confident, I'll let you know.

There are also a couple of ways you can help us. {{ argument_how_colleagues_can_help }}

In four lines. The problem: {{ argument_problem_short_name }}. What you'll notice: some disruption in the areas I mentioned, while everything else works as usual. What we're doing: a temporary fix soon, and a permanent fix after that. And what you can do: share the simple message with customers, and report anything unusual to us.

I'll send a short written summary of this after the meeting, so you have it for reference. And I'll give you an update by {{ argument_next_update_time }}, or earlier if anything changes.

Is there anything I explained that wasn't clear? Please ask, even if it feels basic. If one person is wondering about something, others usually are too.

We know this isn't ideal, and we're doing everything we can to get it sorted out quickly and safely. Thank you for your patience.
